### 三项能力的口径

**1. SARIF 2.1.0（`scan --sarif FILE`）**

- 只导出报告里**已经存在**的 Finding：`fail` → level 由既有 `severity` 固定映射
  (`critical→error` / `major→warning` / `minor→note`)；`unknown` → `level=note` + `properties.status=unknown`；
  `skipped` **不导出**（不适用不是问题）。
- `ruleId` 取既有**原因码**；`tool.driver.rules` 按 id 去重并带 `clause` / `doc_id` / `target` / `scope` / `severity`。
- 失败件 → 一条 `level=error`、`ruleId=scan_error` 的结果（失败件不静默消失）。
- `generated_at` 为空时**不写** `startTimeUtc`（产物保持无时钟 → 可复现）。
- `artifactLocation.uri` 统一 POSIX 分隔符。

**2. 单文件 HTML（`scan --html FILE`）**

- 内联 CSS、**零 JS、零外链**（测试断言 `http://` / `https://` 出现 0 次）——打开报告不产生任何联网。
- 段落与 `report.md` 对齐（范围 / 依据 / 逐件可观测性 / 逐字段 / 违规 / 失败件 / 对账 / 结论），
  强制免责声明原样保留。
- 所有来自输入的值（件路径、card_id、错误信息）经 `html.escape(quote=True)` 转义。

**3. `rules` 只读子命令**

- 缺省**同时列出 verified 与 pending**（"哪条还没核对"本身是用户需要的信息）。
- `--scope` / `--status` 过滤；`--mapping` 附带字段映射表；`--json` 机器可读。
- **纯只读**：不判定、不写盘（测试用"跑前跑后数据目录文件与字节完全相同"锁定）。
- 退出码 0；数据目录读不到由 `effective_ruleset` 抛 `RulesetError` → exit 3（沿用既有语义）。

### 11.1 首轮 CI 暴露的 4 处真实缺陷（已修，均有测试锁住）

push 后首轮 CI（run `39255079702`）**2 红 6 绿**，全是**既有代码在现代化后显形**的真缺陷，
不是断言问题：

| # | 位置 | 症状 | 根因 | 修法 |
|---|---|---|---|---|
| 1 | `tests/test_gui_tabs.py` | 16 项**全过**但进程退出码 `0xC0000409`/127 | 16 个用例各建 `MainWindow` 从不 `close()`；PySide6 6.12 下留给解释器退出期统一析构 → abort | module fixture teardown 里 close + deleteLater 所有顶层窗口 → `processEvents` → `QApplication.shutdown(instance)` |
| 2 | `tools/build_exe.py` | 构建**开始前**崩 `UnicodeEncodeError`（"已清理 build/ 与 dist/"） | GH Actions Windows runner 无控制台时 stdout 是 **cp1252** | 加 `ensure_utf8_stdio()`（仅非 UTF-8 家族才 reconfigure） |
| 3 | `tests/test_generators.py`、`tests/test_parse_regression.py` | `PytestUnhandledThreadExceptionWarning` + `UnicodeDecodeError`（被降级成 warning，真失败点被掩盖） | `text=True` 默认按本机 locale（cp1252）解码子进程 UTF-8 中文输出 | 显式 `encoding="utf-8", errors="replace"` + `PYTHONIOENCODING=utf-8` |
| 4 | `tools/verify_package.py`、`tools/_utf8_stdio.py` | 验收**全过**后在最后一行"冻结态包验收：通过"上崩 | 同 #2；且 `python -m tools.*` 时 `sys.path[0]` 是仓库根 → `ModuleNotFoundError: _utf8_stdio` | 共享防护模块 + 两个入口显式把 `tools/` 插入 `sys.path` |
