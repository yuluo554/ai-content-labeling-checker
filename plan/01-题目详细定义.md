## 一、项目介绍

《人工智能生成合成内容标识办法》（国家互联网信息办公室、工业和信息化部、公安部、国家广播电视总局联合发布，**国信办通字〔2025〕2 号**）自 **2025-09-01 施行**，配套**强制性国家标准 GB 45438-2025《网络安全技术 人工智能生成合成内容标识方法》**同日实施，确立了"**显式标识 + 隐式标识**"双轨制度：显式标识（文字/图形/语音提示）与隐式标识（文件元数据中的生成合成内容属性信息、服务提供者名称/编码、内容编号等）。平台与服务提供者面临真实合规压力：**我产出的内容标识是否合规、从外部收到的内容标识是否完整、批量内容怎么高效核验、核验结论怎么留证据**。

现有开源生态中，**合规口径的标识核查工具近乎空白**：GitHub 检索"AI generated content watermark detection"仅 2 个项目、"AI生成内容标识"仅 3 个 ≤1-star 项目；而高 star 项目恰恰是**去除水印/反合规**方向（watermarks-remover 类），C2PA 生态是**标准与解析库**而非合规核查产品。本项目要求开发一款**AI 生成合成内容标识合规核查器**：以**办法 + 强制国标**为规则源，实现"显式标识核验 → 隐式标识（元数据）字段核验 → 标识完整性判定 → 合规报告/证据链"的本地闭环，核心特色是**规则库版本化**（办法/国标条款编码为可执行核查规则）+ **元数据字段映射引擎**（按国标字段规范校验存在性/格式/映射）+ **批量扫描**（沿用系列全量批处理招牌）。

## 二、任务要求

> 首期范围限定为 **《标识办法》+ GB 45438-2025 文本/图片/音视频三类内容的标识字段规范**；其余载体（如特定行业叠加要求）留扩展。全部模块遵循"**未挂原文核对不得落库/生效/进入判定路径**"的确定性纪律。

### 1）显式标识核验引擎

- 对内容及伴随信息检查是否具备国标要求的**显式标识要素**（如文本内容的开头/结尾/中间适当位置提示、图片的显著位置提示、音视频的起始提示等）；
- 标识**位置/形式**按国标规则判定合规性（不只"有没有"，还判"位置形式对不对"）；
- 输入支持结构化描述（人工录入元信息）+ 文件解析（可解析的载体自动提取）；输出逐要素判定 + 条款依据。

### 2）隐式标识（元数据）字段核验引擎（亮点）

- 按 GB 45438-2025 的**隐式标识字段规范**逐字段核验：生成合成内容属性信息、服务提供者名称/编码、内容制作编号等字段的**存在性、类型、格式、取值合法性**；
- **字段映射引擎**：不同文件容器/元数据体系（如通用元数据键、扩展字段）到国标字段的映射表可配置，映射规则版本化；
- 输出**字段级核验报告**（缺失/格式错误/取值越界逐项标出 + 条款依据）。

### 3）标识完整性判定与分级

- 综合显式 + 隐式核验结果，按规则判定**标识合规等级**（完全合规/部分合规/不合规）+ 缺失项清单；
- 分级标准挂条款依据；边界情形（如元数据被剥离但显式标识在）显式处理并在基准中枚举。

### 4）批量扫描引擎（工程亮点）

- 目录/清单批量投喂，扫描产出一张**合规总表 + 逐件明细**（沿用系列全量批处理招牌）；
- **性能与稳定性**：大目录分批处理、失败件隔离不中断整批、进度可见；
- 结果可导出（CSV/XLSX）并支持**与上次扫描对账**（新增违规/已修复/持续违规）。

### 5）合规报告与证据链（交付物进入工作流）

- 一键导出**合规核查报告**（Markdown + XLSX）：核查范围、依据清单、逐件逐字段结果、违规清单、结论；
- **证据固化**：每件被核查内容的核验记录（含内容指纹 sha256）随报告固化，可复现对照（沿用系列指纹防篡改招牌）；
- 报告头固定输出**规则库坐标**（办法/国标版本 + 生成时间），保证可比对。

### 6）版本化核查规则库（工程亮点）

- 规则库按 **`依据文件 × 版本`** 组织（标识办法、GB 45438-2025），条款编码为可执行核查规则；
- JSON 化，每条挂文号/标准号与 status（`verified`/`pending`），未核对不得生效；规则库切换即切换核查口径。

### 7）内置评测基准（零 API 依赖）

- **字段规则基准**：元数据字段存在性/格式/取值规则的枚举用例（含边界与畸形输入）；
- **构造真值基准**：程序化构造**带已知标识配置的合成文件**（正确标识 / 缺字段 / 错位置 / 错取值），核验结果与植入真值对账——零 API 依赖可重复，指标写进 README；
- **批量对账基准**：两轮扫描差异对账的确定性验证。

## 六、边界与非目标

- **不做**：**不做去水印/标识规避**（严禁、且为反合规方向，明确列为非目标）；不实现特定厂商私有水印算法破解；不做法务定性结论；不对接平台举报接口。
- **首期范围**：办法 + GB 45438-2025 的文本/图片/音视频标识字段规范；其余载体留扩展。
- **合规红线**：**全本地核查、零上传**（被核查内容可能含商业敏感信息，默认不联网）；**免责声明强制**：核查结论供参考，正式合规认定以监管口径为准；规则库未挂原文核对（status=pending）不得进入判定路径；**工具定位为合规辅助，绝不为规避标识提供任何功能**。
- **数据纪律**：合成样本由生成器构造（含植入标识真值）；**不得收录真实平台内容的完整样本入库**，样本仅留结构与指纹；禁止使用任何真实个人信息/商业内容。
- **品牌隔离**：不复制姊妹项目代码；文档不提其余项目业务领域。
