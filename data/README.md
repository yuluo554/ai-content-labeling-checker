## 三、合成数据纪律

- **合成样本**：全部由 `tools/gen_samples.py` 构造（文本/图片/音视频容器），内容为完全虚构的占位内容，**不得收录任何真实平台内容、真实用户信息或真实商业素材**。
- **植入真值**：每个合成样本按设计植入已知标识配置（正确/缺字段/错位置/错取值），生成器同时输出**期望核验结论**，真值随样本入库，引擎双路对账。
- **字段白名单**：合成服务提供者名称/编码使用明显虚构值（如"示例提供者编码 SYN-0001"），入库登记，不得与真实服务提供者冲突。
- **可复现**：生成器固定随机种子；产出物 sha256 留档；样本随仓库发布（体量受控，超大样本不入仓、仅留生成参数）。

## 四、法律与许可口径

- 规则库 JSON 中的条款信息以"文件号 + 条号 + 要点"形式呈现（规避全文转载），原文以官方页面为准（强制性国标全文获取遵循标准公开渠道口径）；
- data/knowledge/raw/ 快照为官方公文与标准页面（著作权法第五条官方文件不适用版权保护）；
- 合成样本与真值库为本项目自制，MIT 许可随仓库发布。
